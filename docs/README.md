## 阅读顺序建议

1. 先看 `architecture/01-project-structure.md` 建立目录与别名的整体印象。
2. 涉及数据落盘时看 `data/` 与 `setting/`；资料库配置与媒体索引都在 sqlite（`library` / `library_path` / `media_item` / `media_source` / `media_image`，不再是独立 JSON），看 `media/01-media-library.md`；演员的三张表与按名字弱关联的 `media_cast`（`actor` / `actor_alias` / `actor_image` / `media_cast`）与图片落盘看 `actor/01-actor-module.md`；`storage://` 私有协议与媒体源 / 图片取值也归这一层。
3. 涉及文件读写（本机磁盘 / WebDAV / SMB）时看 `file/`。
4. 涉及刮削站点适配（导入 / 编写插件）时看 `plugin/`——插件按**影片信息 / 演员信息 / 翻译**三类彻底独立，契约与迁移看 `plugin/01-plugin-module.md`，类别设计与演员四场景看 `plugin/03-plugin-categories.md`；离线保底方案（r18.dev 数据包）看 `plugin/02-builtin-offline-plugin.md`；写**演员信息插件**时先看 `plugin/04-actor-plugin-examples.md` 的两个真实站点范例与站点口径（要「只调 JSON API、不解析 HTML」的写法就看 `plugin/05-tmdb-plugin.md` §8）；写**影片信息插件**（尤其要同时刮电影与剧集）时看 `plugin/05-tmdb-plugin.md`。
5. 涉及界面改造时看 `ui/` 与 `page/`；刮削进度 / 记录与详情页看 `page/03-scrape-detail-page.md`，刮削任务本身看 `scrape/01-scrape-module.md`；刮削成果的浏览入口（影视墙）看 `page/04-media-wall-page.md`，影视墙的归口单位与扫描 / 刮削链路看 `media/01-media-library.md`（剧集库这种「一整部剧算一条」的库看 `media/02-series-support.md`）；播放窗口与 mpv（Windows 的宿主窗口嵌入 / macOS 的无边框独立窗口两条路径）看 `media/03-mpv-playback.md`（主窗口标题栏的「正在播放」标签也在它 §7.1）；详情页的「手动匹配」（按番号 / TMDB ID / 关键字重刮这一条）看 `media/04-manual-match.md`；演员界面看 `page/05-actor-pages.md`。
6. 涉及唤起系统文件 / 目录选择框（打开、保存、选目录、多选文件）时看 `dialog/`。
7. 涉及演员资料（字段口径、图片目录、演员信息插件、四个抓取场景与合并规则）时看 `actor/01-actor-module.md`。
